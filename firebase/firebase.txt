FIREBASE HOSTING – COMPLETE LAB MANUAL
========================================

AIM
---
To create a simple HTML webpage and host it using Firebase Hosting.


PART 1: OPEN THE FIREBASE WEBSITE
=================================

STEP 1: OPEN FIREBASE CONSOLE

1. Open Google Chrome.
2. Enter this link:

   https://console.firebase.google.com/

3. Press Enter.
4. Sign in using your Google account.
5. If your college provides an account, use that account.


STEP 2: CREATE A FIREBASE PROJECT

1. Click "Create a project" or "Add project".
2. Enter a project name.

   Example: my-lab-website

3. Click Continue.
4. If Google Analytics setup appears, you can disable it for this basic experiment if permitted.
5. Click "Create project".
6. Wait until the project is created.
7. Click Continue to open the project dashboard.

NOTE:
A Firebase project is the container that holds your Firebase services.


STEP 3: OPEN FIREBASE HOSTING

1. Look at the left-side menu.
2. Find the "Build" section.
3. Expand Build if necessary.
4. Click "Hosting".
5. Click "Get started" if the button appears.
6. If Firebase asks you to create a Hosting site, follow the instructions.

IMPORTANT:
You will create the HTML file on your computer. You do not need to paste the HTML code into the Firebase website.


PART 2: INSTALL THE REQUIRED SOFTWARE
=====================================

STEP 4: INSTALL NODE.JS

1. Open this link:

   https://nodejs.org/en/download

2. Download a current supported version of Node.js.
3. Install it using the default options.
4. Open Command Prompt.
5. Type:

   node -v

6. Press Enter.
7. Then type:

   npm -v

8. Press Enter.

If both commands display version numbers, Node.js and npm are installed.


STEP 5: INSTALL FIREBASE CLI

In Command Prompt, execute:

   npm install -g firebase-tools

Wait for the installation to finish.

Firebase CLI allows us to connect our computer to Firebase and deploy the website.


STEP 6: LOGIN TO FIREBASE

Execute:

   firebase login

1. A browser window may open.
2. Sign in with the Google account that has access to your Firebase project.
3. Complete the login process.
4. Return to Command Prompt.

You are now authenticated with Firebase.


PART 3: CREATE THE HTML PAGE
============================

STEP 7: CREATE A PROJECT FOLDER

1. Create a folder on your computer named:

   firebase-hosting

2. Open the folder.
3. Create a file named:

   index.html

4. Open it using Notepad or Visual Studio Code.
5. Paste the following HTML code:

   <!DOCTYPE html>
   <html>
   <head>
       <title>My Website</title>
   </head>
   <body>
       <h1>Welcome to My Website</h1>
       <p>Successfully hosted using Firebase!</p>
   </body>
   </html>

6. Save the file.

IMPORTANT:
If the examiner gives you a different webpage, use their HTML code instead. The main file should still be named index.html.


PART 4: CONNECT THE PROJECT TO FIREBASE
=======================================

STEP 8: OPEN COMMAND PROMPT INSIDE THE FOLDER

1. Open the firebase-hosting folder in File Explorer.
2. Click the address bar at the top.
3. Type:

   cmd

4. Press Enter.

Command Prompt should open with the firebase-hosting folder as the current directory.


STEP 9: INITIALIZE FIREBASE HOSTING

Execute:

   firebase init hosting

Firebase will ask several questions.

Answer them as follows:

QUESTION 1:
"Please select an option"

ANSWER:
Choose "Use an existing project".

QUESTION 2:
"Select a Firebase project"

ANSWER:
Choose the project created earlier.

QUESTION 3:
"What do you want to use as your public directory?"

ANSWER:
Type:

   public

QUESTION 4:
"Configure as a single-page app?"

ANSWER:
Choose No for a simple HTML website.

QUESTION 5:
"Set up automatic builds and deploys with GitHub?"

ANSWER:
Choose No for this basic experiment.

QUESTION 6:
"If asked to overwrite public/index.html"

ANSWER:
Choose No if you already have your own webpage saved there.

Firebase will create the configuration files and public folder.


STEP 10: CHECK THE FILE LOCATION

Your folder should look like this:

   firebase-hosting/
       firebase.json
       .firebaserc
       index.html
       public/
           index.html

IMPORTANT:
Firebase deploys files from the public folder in this setup.

Copy your actual HTML page into:

   public/index.html

Make sure this file contains your webpage code, not the default sample page generated by Firebase.

You can keep the original index.html in the main folder as a backup.


PART 5: DEPLOY THE WEBSITE
==========================

STEP 11: DEPLOY

In the same Command Prompt, execute:

   firebase deploy --only hosting

Press Enter.

Wait until the deployment finishes.

Firebase uploads the contents of the public folder and publishes the website.


STEP 12: GET THE HOSTING URL

After deployment, Firebase displays a URL similar to:

   https://your-project-id.web.app

This is only an example.

Copy the actual URL shown in your terminal.


STEP 13: VERIFY THE WEBSITE

1. Open Google Chrome.
2. Paste the Hosting URL.
3. Press Enter.
4. Check whether your webpage appears correctly.

You can also return to:

   https://console.firebase.google.com/

Open your project and select:

   Build → Hosting

The deployed website and its URL should be displayed there.

Your website is now hosted using Firebase Hosting.


PART 6: IF THE EXAMINER GIVES A DIFFERENT PAGE
==============================================

Suppose the examiner asks you to create a student registration page.

1. Open index.html.
2. Replace the sample HTML with the required HTML code.
3. Save the file.
4. Ensure the updated file is inside the public folder.
5. Execute:

   firebase deploy --only hosting

6. Open the same Hosting URL again.

You normally do not need to create a new Firebase project for every change to the same website.


COMMON ERRORS
=============

ERROR 1: 'firebase' IS NOT RECOGNIZED

Solution:
Run:

   npm install -g firebase-tools

Close and reopen Command Prompt, then try again.


ERROR 2: WRONG PAGE APPEARS

Solution:
Check that your actual webpage is saved as:

   public/index.html

Then deploy again.


ERROR 3: PROJECT NOT LISTED

Solution:
Run:

   firebase login

Sign in using the account that has access to the project.

Then run:

   firebase init hosting

Select the correct project.


ERROR 4: PERMISSION OR BILLING MESSAGE

Solution:
Read the error carefully and use the college-provided project or account if available. Some operations may require additional permissions or billing setup. Do not enter payment details unless authorized.


IMPORTANT COMMANDS TO MEMORIZE
==============================

1. npm install -g firebase-tools

   Installs Firebase CLI.

2. firebase login

   Signs in to Firebase.

3. firebase init hosting

   Connects the folder to a Firebase project and configures Hosting.

4. firebase deploy --only hosting

   Uploads and publishes the website.
